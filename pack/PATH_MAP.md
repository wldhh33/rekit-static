# PATH_MAP · pack 目录名映射

> 背景：`pack` 是在 Windows 上解包时产生的文件名编码损坏（UTF-8 字节被按 GBK 解码）。
> 处理策略：**先记录、不重命名**。原因：`2026-11-15\m3-task-card\work\rekit`、`work\tests`
> 是指向 `pack` 的目录联接；重命名会断开联接，且本工作树当前有另一个会话在使用。
> 重命名安排到维护窗口执行，执行前必须做 sha256 前后比对（见文末清单）。

## 重命名操作手册（维护窗口执行）

1. 确认 `work` 下没有会话在跑（`pack\tools\status.py` 显示无运行任务；人工确认）。
2. 记录基线：`python pack\tools\status.py > before.txt`，并保存 25 + 51 个 `.py` 的 sha256 清单。
3. 逐个目录执行 `os.rename`，**一次一个**；每次后校验：
   - `work\rekit`、`work\tests` 联接仍可访问；
   - 76 个 `.py` 的 sha256 集合不变。
4. 任何一步失败：立即把该目录名改回原 mojibake 名，终止后续步骤。
5. 全部成功后，同步更新 `README.md`、`AGENTS.md`、`CHARTER.md` 中的路径。

## 禁止

- 不要用 `git mv` 批量改名（当前还没有 git 基线，无法回滚）。
- 不要"顺便"移动文件内容；改名与移内容必须是两次独立操作。
