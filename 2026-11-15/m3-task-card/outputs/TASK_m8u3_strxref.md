## 1. 字符串识别口径（先写后做，可被反驳）

代码：`rekit/strxref.py` 模块头 `CALIBER` 与 `CAVEATS`（先于实现写好，再写扫描函数）。

| 要素 | 口径 | 为什么这样定 |
|---|---|---|
| 扫描范围 | 只读数据节**白名单**：`.rodata`、`.rodata.str*`、PE `.rdata`。明确排除 `.rodata.cst*`、`.data*`、`.bss`、`.text`、任何可写节；节须 alloc 且有文件字节（SHT_NOBITS / RawSize==0 不扫） | 数据节里大量二进制不是字符串；白名单比黑名单更不容易误报 |
| 编码 | 可打印 ASCII `0x20..0x7E`（含空格）。含 `0x80..0xFF` 的段**一律不报** | 没有语言/区域证据时 UTF-8 与二进制不可区分，不猜；计入 `rejected_high` |
| 最短长度 | 4 字节（不含 NUL） | 更短的段与机器码/对齐填充无法区分 |
| 终止条件 | 必须在同一节内遇到 `0x00`；节尾未遇 NUL 的尾段不报 | 没有终止边的「可打印段」很可能是被截断的二进制 |
| 重叠 | 按 `0x00` 切成**互不相交**的段，只报整段，不做滑动窗口 → 同一字节不会属于两条字符串，不存在「保留哪一条」的取舍 | 滑动窗口会把父串的任意子串都报出来，误报率极高 |
| 「重叠」的实际两种情形 | ① 引用点落在字符串**内部**（非起点）→ 记 `suffix`（**556** 条），**不计入**唯一回指；② 同一字符串被多处引用 → `multi`（**434** 条） | 这两种才是本轮真正要区分的「不唯一」 |
| 立即数引用（次级口径） | 立即数值恰等于字符串起点算引用点，但要求 `≥ 0x100000` | PIE / 低地址镜像里小整数与地址不可区分，宁可不报 |
| 数据节指针值（4/8 字节） | **不认作引用点**（数据→数据，无函数归属），只作为 no_site 归因证据 | 引用点要能落到函数；指针表没有函数归属 |

拒绝量逐样本单列（`rejected_binary / rejected_short / rejected_high / no_nul_tail` 及其字节数），
不把「没报」当「没有」。

### 2.1 零值必须可解释（三种零，分别写原因）

| 样本 | 零的类别 | 结构性原因（模块给原文） |
|---|---|---|
| dyn_pie / dyn_nopie / dyn_execstack / dyn_norelro | 白名单节在、字符串 0 | 「白名单节内没有 NUL 终止的可打印 ASCII 段（长度≥4）」——这些 fixture 的 `.rodata` 只有 0–4 字节 |
| minidll.dll / minipe.exe / minipe_fakerich.exe | 无白名单节 | 「白名单只读数据节缺失（本样本没有 .rodata/.rodata.str*/.rdata）」；minidll 的导出名在 `.edata`（不在白名单，见 §5） |
| upx_* | 无白名单节 + 无 `.text` | 加壳后节名变 `UPX0/UPX1`；`coverage.no_code_reason` 明写「引用点整体不可判定」，不报 0 个引用点当结论 |

### 2.2 no_site 四类归因 + 一个额外正名

| 归因 | 条数 | 证据形态 |
|---|---:|---|
| 跨界 | 262 | 4/8 字节对齐的指针值等于该串起点，且落在**非白名单装载节**（`.data` / `.data.rel.ro` 等） |
| 未解出 | 0 | `.text` 内 8 字节对齐指针值等于串起点、且不落在已解出指令起点（本轮样本无命中） |

**额外正名（不掩饰）**：外部 objdump 证明，有 **5039 个引用点、276 条字符串**位于

`counts.coverage.note` 与 `CAVEATS`，并在 verify 汇总里单列。busybox 覆盖仅 0.1%
（stripped musl 静态、种子几乎只剩入口），是缺口的主要来源。

## 3. 引用点期望值：来源与可失败自证

**期望值不取被测实现**——`verify_strxref.py` 不 import `rekit.expr`，也不复用
`strxref` 的扫描/解析结果：

1. 地址期望：`objdump -d -M intel --insn-width=16` 每行的**原始字节列**给出指令长度，
   rip 相对操作数用 `[rip±0xdisp]` 文本、立即数用操作数里的 `0x...` 文本，
   目标由本脚本自己算：`addr + len + disp`（不是读 objdump 的注释）。
   PE 用独立解析出的 `.text` 起始地址归一化（`delta = objdump首址 − 节RVA`）。
2. 字符串期望：本脚本用**自己的** ELF/PE 节头解析（`struct` 直接读，不 import
   `rekit.elf` / `rekit.pe`）重切一遍字符串集合，与模块报出的 addr/len/text 逐项相等。
3. 漏报判定分三种：`a ∈ 已解出且 unlifted` → 只计数；`a ∉ 已解出` → 未解码代码，只计数；
   其余 → **失败**。三种计数都进汇总，不静默丢。

`--selftest`（基线 `bin_ls.elf`，先验证基线零失败，再注入）：

| 注入 | 必须被检出为 |
|---|---|
| 把某引用点 target 改成 `target+1` | 「与 objdump 不符」 |
| 删掉一个 objdump 能看到的引用点 | 「漏报引用点」 |
| 伪造一条字符串（文本与文件字节不符） | 「误报字符串 / 文本与文件字节不符」 |
| 把与 callfacts 同址的站点函数归属改错 | 三层对账 `layer_bug` |
| 把某站点函数换成一个声明 end 的种子（地址在域外） | `function_range` / `layer_bug` |

实测五类全部检出，基线零失败 —— 检查器不是空转的。

## 4. 与既有层对账

三层：`strxref`（本层）/ `callfacts`（事实层）/ `callgraph`（调用图层）。同一「引用点」若
同时是调用点，则比对函数归属与指令字节。

- **交集 0**：本层 3732 个引用点没有一个是调用点（调用点经 `call [rip+槽]` 的槽是导入表，
  不是字符串），三层交集**结构上为空**。报告里 `crosscheck.note` 明写「无非空对账对象」，
  不把 0 交集当成「对账通过」。
- **函数域核对 3691**：对每个站点，用 recdesc 种子里**声明的函数 end** 检查
  `start ≤ site < end`；越界即 `layer_bug`。实测冲突 **0**。
- **反向语义检查**：callfacts 里 `call_kind == "direct"` 且目标落在字符串起点 → `layer_bug`；
  实测 **0**（链接器不会把控制流转进 `.rodata`）。
- 三类归因沿用 sitejoin：`layer_bug`（实现/口径错）、`caliber_difference`（口径差异）、
  `data_anomaly`（同一指令字节不一致）。本轮三类均为 0。

## 5. 已知口径缺口（明写，不当作结论）

| 缺口 | 影响 | 处理 |
|---|---|---|
| Go/Rust 字符串是 (指针, 长度) 长度分界、不以 NUL 终止 | hello_go_linux 只报 7 条、hello_go.exe 3172 条（`.rdata` 里恰好有 NUL 分隔的片段才被报出） | 写入 `CAVEATS`，拒绝字节数单列；不猜长度表 |
| 未解码代码里的引用 | objdump 证明 5039 个引用点、276 条字符串在本层不可见 | 覆盖率 + 缺口数单列；`refs` 声明为**下界** |
| 表达式层 unlifted（VEX/EVEX 等） | 19 个命中（外部 objdump 判定）、全样本 unlifted 数万条 | `unlifted` 单列计数，不猜操作数 |
| PE 导入名前的 2 字节 hint | 导入表指针指向 `串起点−2`，导入名多归入「无证据」 | `CAVEATS` 明写；不把 `−2` 当引用点 |
| PE 导出名在 `.edata` | minidll 的导出名不报 | `.edata` 不在白名单；`CAVEATS` 明写 |
| PIE 低地址立即数 | imm 引用有 `0x100000` 下限，PIE 样本的 imm 引用整体少报 | 口径写死；rip 相对不受影响 |

## 7. 方法学新增（R82–R86）

- **R82**：字符串识别必须给「编码 / 最短长度 / 终止条件 / 重叠处理」四要素；默认只认
  NUL 终止的可打印 ASCII，UTF-8 与长度分界字符串不报。宁可少报，不猜编码。
- **R83**：引用点只在**已解出指令集合**内认定；必须同时报代码覆盖率与「外部工具量化的
  未解码代码漏报数」，不得把「本层没扫到」写成「没有引用」。
- **R84**：引用点期望值必须由外部工具（objdump 字节 + 地址算术）独立算出；`--selftest`
  必须注入「篡改目标 / 删除站点 / 伪造字符串 / 函数归属矛盾 / 函数域越界」五类错例并全部检出。
- **R85**：「无白名单数据节」「有白名单节但无字符串」「无代码节」是三种不同的零值，
  必须分别给出结构性原因，不能都写成 0。
- **R86**：三层对账交集为 0 时，必须写明「无非空对账对象」并给出非零的替代核对项
  （本轮的函数域核对 3691 条），不得把空交集当作对账通过。
